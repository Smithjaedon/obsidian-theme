# Obsidian Dark

A minimal dark theme for Zed and VS Code. Dark grayscale UI with no distracting colors — syntax only.

## Zed

Copy `obsidian.json` to `~/.config/zed/themes/` and select "Obsidian Dark" from the theme picker.

## VS Code

Copy `themes/obsidian-dark-color-theme.json` to `~/.vscode/extensions/` or use it via Command Palette > Preferences: Color Theme > Install from VSIX.
